# Tabaix llms.txt Auto Update

A WordPress plugin that regenerates `llms.txt` at the site root whenever a post is published, updated, trashed, untrashed or deleted — so AI answer engines always see the latest guides and coupon codes.

Built for [tabaix.com](https://tabaix.com/). Free to use and share (GPLv2 or later).

## Features

- **Auto-regeneration** — `llms.txt` rebuilds itself on every post publish, update, trash, untrash or delete. No manual editing.
- **Static header preserved** — the hand-written intro, Key pages, Free tools and Tabaix products sections are kept exactly as written; the plugin never rewrites them.
- **Latest guides section** — rebuilt from the 25 most recent published posts, newest first, as `[Title](permalink)` links.
- **Coupons section** — lists the active coupon codes with their offer, one line each. When the [Tabaix Coupons Sync](https://github.com/Tabaix/tabaix-coupons-sync) plugin is active, the coupons are read from it automatically; otherwise a built-in list is used.
- **Settings page** — **Settings > llms.txt** has a "Regenerate now" button, the last regeneration time, and whether the file is writable. If `llms.txt` is not writable, a clear admin notice is shown instead of failing silently.
- **Admin-only** — only admins can trigger regeneration (capability check + nonce). No new dependencies, no external requests, no tracking.

## Requirements

- WordPress 5.8 or later (tested up to 6.8). No extra libraries — the plugin only uses core WordPress functions.

## Installation

1. Download the [latest release](https://github.com/Tabaix/tabaix-llms-auto-update/releases) (or clone this repo).
2. Upload the `tabaix-llms-auto-update` folder to `/wp-content/plugins/`, **or** in WP Admin go to **Plugins > Add New > Upload Plugin** and install the ZIP.
3. Activate **Tabaix llms.txt Auto Update**. Activation regenerates `llms.txt` once.

## Usage

- Open **Settings > llms.txt** and click **Regenerate now** to confirm it works.
- Verify the output in a terminal:

```bash
curl -s https://tabaix.com/llms.txt | sed -n '/## Latest guides/,/## Coupons/p'
```

- From then on, every post you publish or update rebuilds the file for you.

## FAQ

**I edited the "Latest guides" section by hand and it disappeared. Why?**
That section is generated by the plugin. Edit a post (or click "Regenerate now") and it rebuilds from the 25 newest published posts.

**How do I add or change a coupon code?**
If the [Tabaix Coupons Sync](https://github.com/Tabaix/tabaix-coupons-sync) plugin is active, add or edit the code at **Settings > Coupons**, then click "Regenerate now" under **Settings > llms.txt** (or publish any post). If it is not active, edit the `tabaix_llms_default_coupons()` list in `tabaix-llms-auto-update.php` (or filter `tabaix_llms_coupons`), then regenerate.

**The settings page says llms.txt is not writable. What do I do?**
Make the site-root `llms.txt` file writable by the web server (or, if it does not exist yet, make the site root writable once so the plugin can create it). The plugin reports this with an admin notice instead of failing silently.
