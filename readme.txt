Regenerates llms.txt at the site root whenever a post is published, updated, trashed, untrashed or deleted.

== Description ==

This plugin keeps https://tabaix.com/llms.txt fresh without any manual editing.

* The hand-written header (intro, Key pages, Free tools by category, Tabaix products) is preserved exactly as it was written — the plugin never rewrites it.
* The "Latest guides" section is rebuilt on every publish, update, trash, untrash or delete: the 25 most recent published posts, newest first, as `[Title](permalink)` links.
* The "Coupons" section lists the active coupon codes with their offer, one line each. No commission rates are ever written — those are internal only.
* A "Regenerate now" button lives under Settings > llms.txt, with the last regeneration time and whether the file is writable. If llms.txt is not writable, a clear admin notice is shown instead of failing silently.
* Only admins can trigger regeneration (capability check + nonce). No new dependencies, no external requests, no tracking.

The generated "Latest guides" replaces the old hand-maintained "Popular guides and reviews" list, and the generated "Coupons" section replaces the old hand-maintained "Coupon codes" list. The "## Optional" sitemap link at the end is preserved.

== Installation ==

1. Upload the `tabaix-llms-auto-update` folder to `/wp-content/plugins/`, or install the ZIP via WP Admin > Plugins > Add New > Upload Plugin.
2. Activate "Tabaix llms.txt Auto Update". Activation regenerates llms.txt once.
3. Open Settings > llms.txt and click "Regenerate now" to confirm it works.
4. Verify: `curl -s https://tabaix.com/llms.txt | sed -n '/## Latest guides/,/## Coupons/p'`

== Frequently Asked Questions ==

= I edited the "Latest guides" section by hand and it disappeared. Why? =

That section is generated by the plugin. Edit a post (or click "Regenerate now") and it rebuilds from the 25 newest published posts.

= How do I add or change a coupon code? =

If the Tabaix Coupons Sync plugin is active, add or edit the code at
Settings > Coupons, then click "Regenerate now" under Settings > llms.txt
(or publish any post). If it is not active, edit the
`tabaix_llms_default_coupons()` list in `tabaix-llms-auto-update.php` (or
filter `tabaix_llms_coupons`), then regenerate. Never add commission rates
— those stay internal.

= The settings page says llms.txt is not writable. What do I do? =

Make the site-root `llms.txt` file writable by the web server (or, if it does not exist yet, make the site root writable once so the plugin can create it). The plugin reports this with an admin notice instead of failing silently.
